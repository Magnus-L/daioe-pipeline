# WHY numpy AND pandas ARE PINNED HARD
# The port's whole claim is bit-exact reproduction of Erik's Stata construction, and
# that rests on float32 storage semantics and on group-summation order inside
# `collapse (mean)`. Both are library-version-sensitive: a newer pandas can change
# groupby accumulation and silently move the last ULP, which is precisely the tolerance
# the validation gate works at. Treat these two as part of the method, not as
# housekeeping, and re-run the full validation before changing either.
#
# THREE OF THESE ARE IMPLICIT
# pyarrow (parquet intermediates), xlrd (legacy .xls inputs) and openpyxl (.xlsx) are
# never imported by name anywhere in src/; pandas loads them on demand. Reading the
# source will not find them. All three were discovered by running the pipeline, which
# is the only reliable way to establish this list.
